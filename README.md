# Midnight Arcade

A private-feeling game hub for friends, with Krillion available directly from the page or in a new tab.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save.

The published address will appear in the Pages settings.

## Features

- One-click launch in a centered game dialog
- Full-screen friendly mobile layout
- Direct-link fallback that opens Krillion in a new tab
- Dark, neon arcade presentation

Krillion is loaded from its own public website. If it disallows embedding, use the **Open in new tab** button.
