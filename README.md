# KRILLION

A niche-answer party game with a playful twist: obvious answers score low, but the rarest ideas score high. Pick a strange, specific answer and follow the trail into the long tail.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Play

- Answer five unconventional prompts.
- Common answers reveal low rarity scores.
- Surprising, specific answers build score and streaks.
- Finish by sharing your final score.
